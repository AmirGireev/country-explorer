# Country Explorer

Browse all countries of the world, search them and save favorites.

**Live demo:** [https://YOUR-APP.vercel.app](https://country-explorer-silk-beta.vercel.app/)

## Features

- Country list with flags, search and favorites (saved in the browser)
- Detail page per country (dynamic routes)
- Loading, error and not-found states

## Tech Stack

Next.js (App Router), React, TypeScript, Tailwind CSS, REST Countries API, Vercel
